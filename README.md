# Hugin Munin Error Labelling

## Install dependencies
The automatic error detection notebook require Stringalign.
Also, as Stringalign is an extension module written in Rust it needs a Rust compiler to be installed (because it doesn't provide pre-compiled wheels yet).

The best way to install Rust is by following the [rustup](https://rustup.rs/) installation instructions.
